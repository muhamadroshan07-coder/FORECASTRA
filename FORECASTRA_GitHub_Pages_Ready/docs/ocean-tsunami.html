OFFICIAL TSUNAMI STATUS

INCOIS Tsunami Early Warning

INCOIS operates India's tsunami early-warning centre using seismic data, bottom-pressure recorders, tsunami buoys, tide gauges and decision-support models.

SATELLITE / UNDERWATER

GAGAN, NavIC & ocean sensors

GAGAN augments GPS navigation; it is not an underwater imaging satellite. NavIC is a navigation system. INCOIS tsunami buoys use a seabed pressure recorder connected acoustically to a surface buoy, which relays data by satellite.
